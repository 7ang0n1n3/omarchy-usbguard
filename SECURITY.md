# Reporting security issues

Use GitHub's private vulnerability reporting option, if enabled, at
https://github.com/7ang0n1n3/omarchy-usbguard/security/advisories/new.
If unavailable, open an issue requesting a private contact without including
exploit details, device identifiers, serial numbers, or policy contents.

For ordinary bugs use https://github.com/7ang0n1n3/omarchy-usbguard/issues.
Include the plugin commit, Omarchy and Quickshell versions, reproduction steps,
and redacted logs. Security fixes and compatibility are not guaranteed for
unreleased working copies. See VALIDATION.md and RELEASE-PREFLIGHT.md for the
tested scope and outstanding release checks.
